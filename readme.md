## About this repository

- Daily coding practice on LeetCode
- Mostly implemented in Python
- Focus on problem-solving, logic building, and optimization
- Stored in GitHub so progress can be reviewed over time

## Repository structure

The files in this repository include solutions for various LeetCode problems such as:

- `Two-sum.py`

- `sum-of-all-odd-length-subarrays.py`
- `sum-of-squares-of-special-elements.py`

Each file contains a solution to a specific problem with code and logic written to solve the challenge.

## How to use

1. Open any `.py` file in the repository.
2. Read the problem description and the solution logic.
3. Run the file locally in Python to test the output.

Example:

```bash
python Two-sum.py
```
